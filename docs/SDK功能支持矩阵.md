# 德佟 LPAPI SDK 功能支持矩阵

核对依据为德佟 LPAPI 公开头文件。该 SDK 依赖 UIKit，不能直接作为 macOS 26 原生框架链接，因此 P1 Label 对桌面端适用能力进行了原生实现。

| SDK 能力 | P1 Label 状态 | 实现 |
|---|---|---|
| 搜索、连接、断开打印机 | 已支持 | USB 自动发现；CoreBluetooth 扫描、连接和断开 |
| 当前打印机名称 | 已支持 | 打印机窗口和状态栏显示当前接口及设备名 |
| 打印机详细信息 | 部分支持 | 名称、接口、连接及耗材状态可用；固件/硬件版本缺少 P1 公开读取命令 |
| 纸张间隔类型和长度 | 已支持 | 连续纸、间隙纸、黑标纸及间隙长度 |
| 浓度、速度、反色 | 已支持 | 任务级参数；反色由原生栅格器可靠处理 |
| 开始/结束绘制、预览、打印图片 | 原生替代 | SwiftUI 编辑器、Core Graphics 栅格器和打印效果预览 |
| 元素旋转和对齐 | 已支持 | 每个元素可旋转；文字支持左、中、右对齐 |
| 文字及字体样式 | 已支持 | 自定义字体、粗体、斜体、下划线、删除线 |
| 二维码 | 已支持 | 原生二维码生成，默认 M 级纠错 |
| 一维码 | 部分支持 | 已支持 Code 128；其他 SDK 制式尚未开放 |
| 图片和阈值 | 已支持 | 阈值、Otsu、Floyd–Steinberg、Atkinson、Bayer |
| 直线、矩形、椭圆、圆 | 已支持 | 原生矢量绘制；等宽等高椭圆即圆 |
| UIView/UIImage 绘制 | 不适用于 macOS | 使用 AppKit/Core Graphics 等价替代 |
| SDK 内置扫描列表 | 原生替代 | 独立“打印机”窗口 |
| 打印机状态回调 | 已支持 | 就绪、缺纸、开盖、过热、电压、打印头、碳带、标签卷 |
| 支持/排除型号前缀 | 已支持当前目标 | 仅发现德佟 P1 USB 标识及名称符合 P1 的蓝牙设备 |
| iOS 后台打印 | 不适用于 macOS | macOS 应用生命周期无需此接口 |
| 固件升级 | 主动不开放 | 缺少官方固件校验和恢复规范，避免损坏设备 |

“部分支持”不是连接或打印链路缺失，而是未提供缺乏可靠原生编码器或公开 P1 设备命令的扩展能力。
